# Akan Name Generator

## Author

**Name:** Salim

## Project Description

The Akan Name Generator is a simple web application that helps users discover their traditional Akan name based on their birth date and gender.

The application calculates the day of the week the user was born and displays the corresponding Akan name according to the Akan naming tradition of Ghana.

## Features

* Select your birth date.
* Choose your gender.
* Calculate the day of the week automatically.
* Display your Akan name.
* Validate user input using JavaScript.
* Reset the form to generate another Akan name.
* Simple and responsive user interface.

## Technologies Used

```bash

```

Open the project folder:

```bash
cd akan-name-generator
```

Open the project in Visual Studio Code, then open `index.html` in your web browser.

## How to Use

1. Open the application.
2. Select your birth date.
3. Select your gender.
4. Click **Generate Akan Name**.
5. View your birth date, the day of the week you were born, and your Akan name.
6. Click **Reset Form** to clear the form and start again.
